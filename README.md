After running the script, you can provide a specific path to scan or simply press Enter to scan the mods folder.

Mods are categorized into Verified, Cheat, and Unknown; a category is displayed only if it contains at least one mod.

You can review the mods based on two identifiers: the real mod name and the nickname.

For example, if I have only one mod and it is verified, it appears like this:
```txt
                Verified Mods:

 [ Real Name  - - - - - - - - - - -  Nickname ]

> FPS Reducer                   meteor-1.21.11.jar
```

As shown, I had renamed the "FPS Reducer" mod to "Meteor", and it was correctly identified; this works in reverse as well.

Note: There is no need to worry, as the mod's status is determined by analyzing the mod's internal strings.
